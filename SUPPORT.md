# 支援說明 / Support

## 繁體中文

本儲存庫為 `microsoft/markitdown` 的 Windows 原生維護 Fork。

### 回報問題與求助

- **Windows 11 維護問題**：若遇到本 fork 的腳本（`tools/`）、Windows CI、繁體中文文件或 Windows 相容性問題，請至 [SanHsien/markitdown Issues](https://github.com/SanHsien/markitdown/issues) 回報。
- **MarkItDown 核心產品問題**：若為核心文件轉換邏輯、新格式支援或跨平臺通用功能之缺陷，建議優先查詢並回報至官方上游 [microsoft/markitdown Issues](https://github.com/microsoft/markitdown/issues)。

---

## English

This repository is a Windows-first maintenance fork of `microsoft/markitdown`.

### Filing Issues and Getting Help

- **Fork-specific & Windows maintenance**: If you encounter issues with fork maintenance scripts (`tools/`), Windows CI, or Windows compatibility enhancements, please open an issue at [SanHsien/markitdown Issues](https://github.com/SanHsien/markitdown/issues).
- **Core product & converter engine**: For core document conversion behavior, new format requests, or upstream platform bugs, please check and file issues with the upstream repository at [microsoft/markitdown Issues](https://github.com/microsoft/markitdown/issues).
